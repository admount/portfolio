# Iron Dominion

A real-time strategy game in the classic medieval style, in one self-contained `index.html` (no build step, no assets; all art is drawn procedurally on canvas).

Open `index.html` in a browser to play.

## Features
- Four resources (food, wood, gold, stone), villagers who gather, carry and drop off at camps, mills and Town Centers
- Farms with automatic reseeding, houses and a 200 population cap
- Four ages (Dark, Feudal, Castle, Imperial) that unlock buildings, units and 20 upgrades
- 11 unit types with attack/armor/bonus-damage counters: villagers, swordsmen, spearmen, archers, skirmishers, scout cavalry, knights, royal guards, rams, mangonels, trebuchets
- 16 buildings including walls, watch towers, castles and a Wonder (hold it 5 minutes to win)
- A* pathfinding, fog of war, minimap, control groups, attack-move, rally points, grid hotkeys
- 1–3 computer opponents at three difficulties that expand, advance ages, research, and send attack waves
- Three map styles and three map sizes, randomly generated each game

## Controls
Left click / drag to select, right click to command. Grid hotkeys `Q W E R T / A S D F G / Z X C V B`, `Ctrl+1–9` groups, `H` Town Center, `.` idle villager, `Del` delete, `P` pause, arrows or screen edge to scroll, wheel to zoom.
